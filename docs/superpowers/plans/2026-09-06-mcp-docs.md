# AList 文档 MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 AList 内提供受限文档目录的 MCP 全文检索和并发安全写入服务。

**Architecture:** `server/mcp` 将官方 Go SDK 的 Streamable HTTP handler 挂到 Gin；`internal/docs` 持有路径校验、文件读写、独立 Bleve 索引与历史记录。所有文件变更经 `internal/fs`，使每种 AList storage 获得一致行为。

**Tech Stack:** Go 1.23, Gin, GORM, Bleve v2, `github.com/modelcontextprotocol/go-sdk v0.8.0`。

**Spec:** `docs/superpowers/specs/2026-09-06-mcp-docs-design.md`

## Global Constraints

- Go module directive must be `go 1.23.0`; do not use APIs newer than Go 1.23.
- The MCP endpoint is disabled by default and never changes WebDAV or `/api/fs/*` behavior.
- All document paths are relative to the configured root and must pass a post-clean containment check.
- Never log MCP tokens or document body content.
- `docs_update`, `docs_delete`, and `docs_move` require optimistic revision checks.
